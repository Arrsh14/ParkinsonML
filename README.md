# ParkinsonMLa

This project focuses on detecting Parkinson’s Disease using machine learning techniques based on biomedical voice measurements.
The goal is to build a predictive system that can help in early diagnosis by analyzing voice-related features.

⸻

🧠 Problem Statement

Parkinson’s Disease is a progressive neurological disorder that affects movement and speech.
Early detection is difficult but crucial. This project uses machine learning models to classify whether a person has Parkinson’s Disease based on extracted voice features.

⸻

📊 Dataset
	•	Dataset contains biomedical voice measurements
	•	Features include jitter, shimmer, fundamental frequency, and noise-to-harmonics ratio
	•	Target variable:
	•	0 → Healthy
	•	1 → Parkinson’s Disease

⸻

⚙️ Technologies Used
	•	Python
	•	NumPy
	•	Pandas
	•	Scikit-learn
	•	Google Colab

⸻

🧪 Machine Learning Model
	•	Algorithm: Support Vector Machine (SVM)
	•	Data preprocessing:
	•	Train-test split
	•	Feature scaling using StandardScaler
	•	Model evaluation using accuracy score
